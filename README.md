# Pi Chat UI 🎨✨

A professional, feature-rich web interface for the `pi-coding-agent`. This UI replicates the full power of the Pi TUI in a modern, developer-centric browser environment.

## 🚀 Key Features

- **Real-time Streaming**: Watch the agent think and respond in real-time with zero lag.
- **Professional Developer Theme**: A sleek "Sparkle Orange" dark aesthetic inspired by modern IDEs (VS Code/GitHub Dark).
- **Live SVG Rendering**: Diagrams and graphics generated by the agent render instantly as inline vector images.
- **Code Diff Viewer**: Visualize file modifications with professional GitHub-style side-by-side or inline diffs.
- **Full CLI Parity**: Complete support for all `pi` slash commands:
  - `/settings`: Configure Thinking Level, Auto-compact, Steering, and more.
  - `/model`: Interactive provider and model selection.
  - `/history`: Browse and resume previous sessions from your workspace.
  - `/stats`: View real-time token usage and session costs.
- **Persistent Sessions**: Automatic conversation saving and restoration via the `web-ui` session ID.
- **File Attachments**: Upload files directly to the agent; they are stored in the `uploads/` folder for physical access.
- **Execution Controls**: Busy pulsing indicators and an instant **Stop/Abort** button for long-running tasks.
- **Connection Status**: Real-time "Online/Offline" indicator for the RPC bridge.

## 🛠 Tech Stack

- **Frontend**: React 19, TypeScript, Vite 6
- **Backend**: Node.js, Express, WebSocket (ws)
- **Agent**: `pi-coding-agent` via RPC Mode

## 📥 Getting Started

### Prerequisites

- Node.js (v18+)
- `pi-coding-agent` installed globally:
  ```bash
  npm install -g @earendil-works/pi-coding-agent
  ```

### Installation

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd pi-ui
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the frontend:
   ```bash
   npm run build
   ```

4. Start the server:
   ```bash
   npm start
   ```

5. Open your browser:
   Connect to **`http://localhost:3000`**

## ⌨️ Command Reference

| Command | Description |
| :--- | :--- |
| `/settings` | Open the configuration menu |
| `/model` | Change the active LLM |
| `/history` | List and resume previous sessions |
| `/stats` | Show token usage and session cost |
| `/clear` | Start a completely fresh session |
| `/copy` | Copy last assistant message to clipboard |
| `/fork` | Fork conversation from a specific message |
| `/skills` | List all loaded extensions and tools |
| `/abort` | Stop current agent generation |

## 📂 File Storage

All files uploaded via the 📎 icon are stored in the `./uploads` directory. The agent is automatically informed of the local path, allowing it to read and edit your files directly.
